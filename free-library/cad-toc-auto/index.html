CAD 도면 리스트 반자동 생성 리습

반복되는 시트폼 블록을 기준으로 도면번호, 도면명, 축척을 읽어 AutoCAD 목차표를 생성합니다.

핵심 아이디어

폼 하나에서 SHEET, DWG NO, TITLE, SCALE 값 칸을 한 번 지정하면, 같은 이름의 시트폼 블록 전체를 찾아 동일한 상대 위치의 텍스트를 읽습니다.

지정한 폼 세팅은 현재 DWG 안에 저장되므로, DWG를 저장하면 다른 PC에서도 같은 기준으로 다시 사용할 수 있습니다.

기존 도면을 속성 블록으로 바꾸지 않아도 일반 TEXT/MTEXT 값을 이용할 수 있습니다.

cad_toc_auto.lsp 다운로드 2014 호환판 다운로드 자동로드 파일 다운로드 전체 패키지 다운로드

로드

(load "C:/Users/kimyj/cad_toc_auto.lsp")

또는 AutoCAD의 APPLOAD 명령으로 리습 파일을 로드합니다.

자동 로드

  1. cad_toc_auto.lsp 파일을 계속 둘 폴더에 저장합니다.
  2. AutoCAD에서 APPLOAD를 입력합니다.
  3. Startup Suite 또는 시작하기 모음에서 Add/추가를 누릅니다.
  4. cad_toc_auto.lsp 파일을 등록합니다.
  5. 새 도면을 열어 TSET/TLIST 명령어가 바로 먹는지 확인합니다.

이 작업은 한 번만 하면 됩니다. 파일 위치를 옮기면 Startup Suite에서 다시 등록해야 합니다.

사용 순서

TSET

긴 명령어는 TOCFORMSET입니다. 짧게는 TSET만 입력하면 됩니다.

  • 반복되는 시트폼 블록 하나 선택
  • SHEET NO 값 칸 지정
  • DWG NO 값 칸 지정
  • TITLE 값 칸 지정
  • SCALE 값 칸 지정
  • DWG 저장
TLIST

긴 명령어는 TOCFORMSCAN입니다.

같은 폼 블록들을 스캔해 SHEET / DWG NO / TITLE / SCALE 표를 생성합니다.

폼 모양이나 방향이 완전히 다른 종류가 섞인 도면만 TADD로 추가 등록합니다.

보조 명령

  • TOCSEMI: 선택 영역의 도면 정보 텍스트를 반자동 인식
  • TOCSEMIALL: DWG 전체 스캔 후 기존 목차 영역 제외
  • TSTAT / TOCFORMSTATUS: 현재 DWG에 저장된 폼 세팅 확인
  • TCFG / TOCCFG: 도면번호/축척 패턴과 출력 기본값 설정

쉬운 명령어 요약

TSET = 폼 기준 설정
TLIST = 도면 리스트 생성
TADD = 다른 폼 종류 추가
TSTAT = 현재 폼 설정 확인
TCFG = 설정값 조정

권장 조건

  • 같은 이름의 시트폼 블록을 반복 사용
  • 도면번호, 도면명, 축척이 폼 안의 일정한 칸에 위치
  • SHEET NO가 비어 있으면 폼의 폭과 높이를 기준으로 왼쪽 묶음부터 위치 정렬
  • 표지나 예외 폼은 수동 보정

AutoCAD 2014에서 안 될 때

  • AutoCAD LT 2014는 AutoLISP를 지원하지 않을 수 있습니다. 일반 AutoCAD 2014인지 확인합니다.
  • ZIP 안에서 바로 불러오지 말고 압축을 풀어 cad_toc_auto_2014.lsp 또는 cad_toc_auto.lsp를 APPLOAD 합니다.
  • APPLOAD 후 Loaded cad_toc_auto.lsp 문구가 떠야 정상입니다.
  • 보안 경고가 뜨면 SECURELOAD 값을 0으로 바꾼 뒤 다시 APPLOAD 합니다.
  • TSET/TLIST가 Unknown command로 나오면 로드가 실패한 것이므로 APPLOAD부터 다시 확인합니다.
